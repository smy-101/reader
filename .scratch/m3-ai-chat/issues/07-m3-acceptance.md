## 真实 LLM 人工验收清单(待执行)

准备工作:本机起后端(`backend` 目录,`READER_DB_URL` 等见 backend/README)与 web(`npm run dev`),上传一本长书(整书 token 明显超过所选模型上下文,如无现成可用任意长篇 EPUB)。

- [ ] **4k 上下文 + 长书:整书装不下自动降级为目标章**(FR-302):AI 设置页填真实服务(Base URL/API key/Chat 模型),上下文上限填 4096 → 对当前书提问"总结这本书" → 回复正常返回(实际只装了目标章),消息下方出现降级说明文案("整书约 N token…已降级为仅装入目标章")
- [ ] **单章超限优雅报错**:上下文上限改小(如 512,低于单章 token)→ 提问 → 明确文案"上下文不足:请换大上下文模型,或配置 embedding 后使用检索式提问",不崩溃不悬挂
- [ ] **断尾说明**:上下文设为"书 + 少量历史"级别 → 连续多轮对话后提问 → 出现"已丢弃最旧的 N 条历史消息"文案(丢最旧、不做摘要)
- [ ] **配错 base URL → 测试连接可读错误**(FR-405):AI 设置页把 Base URL 改成错地址(如 https://api.example.com/v1)→ 测试连接 → chat 探针返回可读中文错误(404/无法连接类),当场发现;改回正确地址 → ok;embedding 留空 → 探针明示跳过
- [ ] **真实模型划选提问流式返回,体验顺畅**(M3 验收第一条):读任意书 → 划选一段 → 问 AI → 回复逐字流式出现,首字等待可接受;消息流可见选中文字引用;刷新/重开会话仍在
- [ ] **S2 直接提问携带当前章**:不划选直接问"这章讲什么" → 引用显示当前阅读位置所在章;翻到另一章再问 → 引用随之变化(D-31)
- [ ] **会话管理**:重命名/删除会话生效;多轮对话上下文连贯(历史进 prompt)
- [ ] **删书级联**:书库删除一本有划线/进度/会话的书 → 确认弹窗明示范围 → 书库与该书会话清净,他书不受影响
- [ ] **桌面壳烟测**(§3.3 矩阵:壳内即 Web):安装/启动桌面壳 → 配置连接 → AI 设置、划选提问流式、删书,与浏览器行为一致
