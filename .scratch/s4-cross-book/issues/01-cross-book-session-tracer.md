# 01: 后端跨书会话域 tracer(全库检索 + 全局提问端点)

**What to build:** 跨书提问的完整后端链路,curl 可演示:两本书嵌入完成后,调用全局提问端点(书前缀之外的独立路径)→ 问题向量化后在**全库就绪书集合**内做纯向量 top-k 检索(未嵌入完成/模型已换的书静默排除)→ 多书检索块按〔书名·第 N 章〕溯源头装配进 prompt(预算复用既有份额贪心与 token 近似计数,历史消息照常填剩余额度)→ SSE 流式返回,事件序列与书级提问完全同构,citations 携带书身份(bookId + 书名快照)随 meta 事件下发,助手消息 refs 落库带同款书字段。跨书会话路由:缺省取最近活跃的跨书会话(无则受理通过后新建,标题 = 首条提问截断);显式会话 id 必须是跨书会话否则可读错误。配套:全局会话列表端点(仅 book_id 为空的会话,按最近活跃排序);前置两态(未配置 embedding / 全库无就绪书)可读中文错误;检索查询由单书过滤泛化为书集合过滤且命中携带书身份(S3 单书检索共用同一路径,书级行为零变化);packages/api-client 扩展全局提问/列表端点类型与 Citation/ChatRef 书字段(向后兼容,S3 引用不填书字段)。零 schema 变更(chat_session.book_id 可空已预留)。
