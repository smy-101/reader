# 03: 检索式上下文 tracer(向量检索 + S3 定位原文后端 + S2 检索式降级翻真)

**What to build:** 对嵌入完成的书,经书级提问端点发起**显式检索式提问**(S3:"作者在哪讨论过 X?"):问题经 embedding 向量化后按书 cosine 检索 top-k 向量块,块内容装配为书内容槽,SSE 流式回复照常;检索先于流式发生,**引用(章节标题 + 原文摘录)随开场元数据事件下发**,并落库到助手消息 refs;提问落入该书最近活跃会话(无则新建,D-32 精神)。前置校验四态——未配置 embedding / 嵌入进行中 / 失败未重试 / 模型已更换——各自可读中文错误。**S2 降级链翻真**(M3 预埋兑现):retrievalAvailable = 已配置 embedding 且该书嵌入完成(当前模型)时,整书、单章都超限自动降级为检索式上下文(发给上游的 prompt 经 stub 断言含检索块而非报错);未嵌入完成时 INSUFFICIENT 文案区分"去配置 embedding"与"等待嵌入完成"两个引导方向。S1(选中文字)行为回归不变;401 防线一致。
