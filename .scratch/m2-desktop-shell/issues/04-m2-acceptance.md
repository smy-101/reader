# 04: M2 人工验收 + 记档(spec 转 done)

**What to build:** 拿 03 产出的 CI 安装包 artifact,在 Windows 上走完 M2 验收清单——安装 → 首次启动经连接设置配后端地址 + token(测试连接确认 ok)→ 书库浏览/过滤 → 批量上传(重复书幂等提示)→ 打开读书(目录跳转、字号/主题)→ 划线(颜色/备注)→ 关闭应用重开、进度与划线接续 → 与浏览器经同一后端互通验证(桌面划的线浏览器可见、浏览器读到一半桌面接续)。另核验首次体验口径:后端不可达 / token 错误时壳内是可读错误而非白屏。全部通过后 spec 与四张票记档转 done。对应验收标准原文:"apps/desktop 打包 Windows 安装包""桌面日常可用,体验同 M1"。

**Blocked by:** 03(需要可安装的 CI 产物)

**Status:** ready-for-agent

- [ ] 安装包安装成功、应用启动,首次配置引导走通(连接设置 + 测试连接)
- [ ] 书库浏览/过滤、批量上传、读书(目录/字号/主题)、划线(颜色/备注)全链路可用,体验同 M1
- [ ] 关闭应用重开:进度与划线接续不丢
- [ ] 桌面端与浏览器经同一后端数据互通(划线/进度双向可见)
- [ ] 后端不可达 / token 错误场景在壳内显示可读错误(非白屏)
- [ ] spec 与 01–04 票 Status 转 done,记档提交
