# 05: 上传防线:幂等 / 413 / 损坏 / DRM

**What to build:** 把上传链路的四类边界情况补齐为可观察行为:同 file_hash 重复上传幂等返回已存在书籍(不重复解析、不新增行/文件);超过 100MB 快速返回 413;损坏文件返回 400"文件损坏"可读文案;疑似 DRM 书返回 400"疑似 DRM 保护,不支持导入"(与损坏区分);一切失败都不建 book 记录、不落任何文件(先解析后落盘)。完成后可演示:四种坏情况各自得到可读文案,库和盘保持干净。

**Blocked by:** 03(EPUB 上传全链路)

**Status:** ready-for-agent

- [ ] 同 file_hash 重传:第二次 200 幂等返回已存在书籍,不重复解析、不新增任何行/文件(D-30 / FR-102)
- [ ] 上传超过 100MB → 413 超限提示(FR-105)
- [ ] 损坏文件 → 400 可读文案("文件损坏"),不建 book 记录、不落盘(D-29)
- [ ] 疑似 DRM 书 → 400 可读文案("疑似 DRM 保护,不支持导入"),与损坏文案明确区分;同样不建记录、不落盘、不解密
- [ ] 仓库内置小型 fixture:一本正常书、一个损坏文件、一本带加密标记的 DRM 构造书
- [ ] 集成测试断言以上四种行为,包括数据库行数与磁盘文件不存在性
